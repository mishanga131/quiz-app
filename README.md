# Quiz App

Лабораторна робота №1 — Компонентна архітектура та стан.
Подгорець Михайло, АТ-251. Номер у списку 21



## Як запустити

```
cd frontend
npm install
npm run dev
```


## Що є

- запитання беруться з `public/api-mock/quiz.json` (10 штук)
- на кожне запитання вибирається одна відповідь (радіокнопки)
- правильна відповідь в компонент запитання не передається
- в кінці показує скільки правильних, наприклад "7 із 10", і розбір помилок
- можна переходити між запитаннями, прогрес зберігається якщо оновити сторінку
- є темна і світла тема
